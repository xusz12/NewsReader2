# 报告工作区修复验证（2026-11-02）

本次验证使用隔离的数据库、临时 CLI 工作目录和 `output/report-repair/` 中的测试产物。真实新闻库仅通过 SQLite `mode=ro` 与 `query_only` 读取，不创建、覆盖或删除正式报告，也不改变新闻已读状态。真实模型沿用现有 CLI/SDK 认证，测试日志不保存凭据或原始服务端错误。

## 已重放的失败

原月报失败批次有1692个来源、163个事件，已引用编号 `N03373` 同时出现在 omitted 中，没有漏处理编号。旧代码因此要求整批修复，修复提示超过输入预算。

新校验在本地去除这一个重复舍弃编号，保留全部163个事件及其文字，剩余1216个明确舍弃来源，模型调用次数为0。缺失来源仍需补审，不会自动算作舍弃。另用真实 Flash 草稿验证了编号缺少 `N` 和 `omitted: [{ref, reason}]` 的确定性规范化；不存在的编号仍拒绝，其他事件错误定位到单个事件路径。带问号的舍弃编号仍交回模型确认；格式修复后若出现覆盖缺口，会只补审缺失来源。局部修复最多三轮，已应用的修复和补审结果持久保存，避免中断后重复整批推理。

无法解析的原始模型响应也会保留，语法修复只接收这份输出，不重新提交新闻材料；明确的 JSON 代码围栏在本地移除。仍然无效的字段修复不会永久缓存。章节须同时通过结构和计划事件覆盖校验；实测一章已有20个事件、漏写1个事件时，复用原稿约16秒完成补齐，主体段落保持不变。旧的仅通过结构校验的章节缓存也会重新检查计划覆盖。

- 本机 CLI 版本为0.166.0。隔离的本地模型服务验证了私有 MCP 的实际调用、独立子任务启动及其沿用主模型。真实模型的3条合成资料测试验证了委派、计划、分章写作和最终保存，并正确保留“整体待批、一期获批”以及“营收增、利润降”的差异。
- 临时会话 `fork_turns="all"` 实测因缺少父会话持久记录而失败；`fork_turns="none"` 可以工作，子任务通过报告工作区读取资料。Fast 始终关闭。
- 全期5678条快照，Terra/Ultra 启用委派能力的分支约448秒完成，输出20个主题、15条简讯、11736个正文字符，引用322个来源。

这些数字来自一次开发验证，过程中补充了提示和恢复逻辑，不能据此宣称固定的提速倍数或质量得分。CLI可能不完整上报委派事件，也不能把“观测到0个子线程ID”解读为没有委派。正文抽查关注日期、数字、相反报道与引用；已进一步要求每段引用直接支持比较口径，禁止将编辑指令写进正文。结构和覆盖校验不是事实正确性的自动认证。

## Pi 输出预算

Flash/max 的旧32K请求实测曾消耗25773个推理 token，只剩约6K token供JSON正文；旧桥接把长度截断与其他失败合并，不能仅凭旧失败记录确定每次失败原因。

采用新预算，同一批301条资料在约260秒内完整产出122个事件；总输出40694 token，其中推理35088 token。这份响应无法装入旧32K额度。当前预算按模型注册表限制预留思考和正文空间，明确区分 `length`，必要时只扩大一次请求预算，始终不修改用户选择的模型或推理程度。

Pi每次仅保持最多3个整理或章节请求在途，失败停止排入剩余任务；候选与完整草稿在适度预算内直接提供给主编辑，避免每翻一页就重新启动推理。完整候选目录在计划保存前持续提供，查询状态或回查来源不会从下一轮无状态请求中丢掉目录。计划支持同批事件编号的明确连续范围，展开后照常检查遗漏、重复和未知编号，减少大规模取舍的编号输出开销。工具拒绝请求时向下一轮保留原请求及具体错误，便于局部纠正。大上下文模型的批次容量自适应，所有初筛舍弃的原始来源仍可检索与恢复。

## Flash 完整月报与审核恢复

同一5678条快照，DeepSeek v4.1 Flash/low 完成6批整理，形成1403个候选事件；295个分配给14章，1108个明确舍弃。最终生成33个主题、93条简讯、28712个正文字符，引用1016个来源。独立重放校验确认：全期每个来源均有取舍、每个候选恰好分配或舍弃、每个计划事件均有章节引用，最终结果与保存的工作区一致。

真实测试覆盖了缺失编号、重复编号、JSON语法错误、章节漏写和一次模型请求失败后的恢复。主编辑首次终审仅明确回读前12章，对末两章只确认保存，因此增加了回读版本门槛：必须通过工具读取每章最新正文；文字改变会撤销该章的旧确认。旧工作区复用全部整理、计划和14章正文，只继续审核，随后完成14章的回读校验。原生Codex委派也用两章合成资料再次验证了这项门槛，约66秒完成。

本次Flash报告经历开发中断、修复和续跑，不能把某一次恢复的耗时当成从头生成的性能基准。全局统筹仍明显耗时；更多字数和引用不等于更高的事实准确率。人工抽查了金额、比较口径、消息归属及部分跨日叙述，并据此明确要求仅有发布时间时使用“X日报道”。回读记录和机械覆盖证明流程完成，不证明模型理解或核实了每个事实。
