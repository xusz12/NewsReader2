# 新闻工作台重构说明

当前以用户提供的 [v2.3.7 设计规范与 Tokens](DESIGN_SPEC_AND_TOKENS.md) 为视觉依据：48px 顶栏、230px 导航、420px 标准列表、760px 正文行宽上限；1024–1439px 桌面列表在 380–420px 间自适应。768–1023px 收起导航但保留列表／正文双栏，768px 以下采用单栏流转。设置页沿用相同分栏与断点。

右栏采用弹性宽度；规范示意图中的 560px 下限在窄桌面无法与其三栏断点同时满足，因此不设硬性最小宽度，确保 1024px 仍无横向溢出。色彩、字体、间距、圆角和动效均通过 `static/style.css` 中的 Token 管理。

## 范围

UI 重构集中在 `static/`，SQLite schema、扫描、正文抓取与模型执行保持兼容。随后按独立项目要求重置版本与 Git 历史，解除原仓库更新源，隔离临时运行目录和 Keychain 账号；数据库保持原结构和路径选择规则，原 DailyNews 数据输入方式继续兼容。删除 `news_summaries.js`，从页面中移除新闻总结、日报、提醒、复盘、跟踪与板块；单篇新闻中文精读和研究 Agent 按原型保留。

静态演示新闻、伪造模型/抓取状态、假连接测试和无后端实现的操作均替换为真实 API 或移除。所有新闻、想法与 Agent 内容按不可信文本渲染。

## 前端文件

- `index.html`：原型骨架、导航、阅读器、Agent 和三栏设置工作台。
- `style.css`：原型设计变量、排版与组件样式，加上真实加载/空白/失败状态、键盘焦点和窄屏修正。
- `app.js`：新闻查询、排序/分页/搜索、滚动标读、全部已读/全部看完、多条想法、导航和快捷键。
- `settings-panel.js`：配置草稿、目录/测试结果竞态、信源设置、密钥、数据库和更新。
- `select-control.js`：设置页自绘下拉菜单、键盘选择、焦点管理与视口边界处理。
- `agent-panel.js`：逐篇会话、流式任务、轮询回退、停止/重试与归档。
- `research-notes.js`：研读评论时间线、个人／Agent 卡片、引用来源、逐篇草稿、发布／取消／删除与焦点恢复。
- `reader-highlights.js`：带原始文本偏移的阅读渲染，正文、结论、要点的高亮恢复和划词引用菜单。
- `ui.js`：请求、错误反馈、安全文本、图标、存储与焦点管理。

## 设置工作台

- 同页切换 `feedColSettings` 与 `detailPanelSettings`，沿用导航、顶栏和主题，不锁住全局操作。
- 中栏支持按分类名称和关键词检索；右栏只显示所选分类。草稿在分类切换、返回阅读和再次进入时保留。
- 保存沿用真实设置 API；撤销更改恢复已保存配置，不写入后端。模型目录、连接测试和数据库选择继续沿用现有接口。
- 768px 以下先显示分类，点击后进入配置详情，可返回分类；退出设置恢复原阅读或想法视图及其位置。支持 `,` 进出、`/` 搜索、`j/k` 分类导航和 `Esc` 返回阅读。

## 验证

`npm run test:ui` 启动 `tests/ui/server.py` 的独立临时数据库。新闻/想法/状态/设置走真实 Flask API；Agent、模型目录、连接测试与文件选择使用确定性测试响应。测试不执行真实模型、密钥修改或应用升级。测试截图中的新闻来自设计原型，仅用于视觉对照。

旧测试以 `vm` 截取旧 `app.js` 的函数文本并依赖旧 DOM ID，部分还硬编码另一份本机项目路径。这些纯前端用例已迁移到 Playwright；退休功能的前端用例随控制器一起移除。原有后端/API 测试保留，SQLite 换库重启与 TTL 的混合测试保留其后端断言。

未改动真实新闻库。要验证真实模型或 opencli，需要在正常启动的应用中使用已有配置执行对应操作。

## v0.0.2 修复

新闻流只保留全部／未读，重要新闻只保留全部／含想法，收藏只保留全部。含想法筛选与当前集合取交集。移除多选操作和来源开关，信源可见性仍在设置中配置。

按原版语义恢复稍后再看状态：加入时抓取全文，默认筛选待阅读；用户在此页打开新闻、正文已可读后，清除 `read_later_at` 并记录 `read_later_done_at`，不修改新闻流的 `read_at`。等待抓取时保留待阅读，正文就绪后再完成；仅进入页面、滚动列表不会完成。稍后再看卡片不用新闻流的已读淡化和红点，仅通过“全文待看／已看完”按钮区分正文阅读状态。新闻流卡片进入视区后完全滑出列表顶部才标读；末尾可见 5 秒后仅标读本次已加载范围，离开范围取消计时。

研究 Agent 的引用来源改用后端接受的 `selection`，无引用时传空值。浏览器回归通过真实 Flask 会话与任务 API 验证普通提问及划词提问返回 202；常规自动化通过模拟运行时验证执行、流式状态和停止；另在临时数据库及会话目录中使用本机已配置的模型实测原文问答与外部检索。

评论通过新表保存，旧 `article_notes` 保持聚合值；原单条笔记、旧版整体更新、Agent 归档以及搜索继续兼容。DeepSeek 新增明确的模型获取和连接测试接口，前端仅收到掩码密钥。

## 设计规范细化

- 列表筛选和图标操作保持一行；排序图标随方向切换，按钮保留可访问名称和提示。日期分组恢复普通滚动。
- 中栏默认排序：新闻流、稍后再看按新闻时间从旧到新；收藏、重要新闻按新闻时间从新到旧；想法按想法更新时间从新到旧。进入新闻集合时恢复该页面的默认排序。
- 卡片用评论图标＋真实数量表示想法，旧客户端改写聚合笔记时自动按一条计数；保存、删除、归档即时同步。
- 已读卡片灰化仅用于新闻流，重要新闻、收藏、想法和稍后再看保持正常色彩；延迟返回的新闻流标读请求也不会灰化其他页面卡片。“写想法”按钮可重复点击展开／收起，收起保留草稿；划词引用仍直接展开编辑器。
- “写想法”展开／收起保持按钮原位：空想法状态不因打开编辑器增加标题和容器内边距，按钮图标等宽，点击按钮不自动滚动；划词引用仍滚动至编辑器。
- 研读想法放在精读容器底部的白底虚线区域，以时间线展示个人和 Agent 评论，含数量、作者、时间及引用。输入框默认隐藏，“写想法”展开，取消或 Esc 收起并保留逐篇草稿，⌘／Ctrl + Enter 发布；发布失败或请求期间继续输入不会清空草稿。正文划词“引用写想法”保留原文／译文及段落来源；Agent 归档经原模型接口提炼后追加独立卡片，保留 Markdown 换行，不改变原对话。每条右上角删除按钮在悬停或键盘聚焦时显现，触屏常显。文章底部没有单独编辑器；未抓取正文时仍隐藏空笔记和正文占位说明。独立想法页继续提供编辑和草稿。
- 空想法区不显示标题、零条徽标和虚线容器，只留下轻量“写想法”；无结构化精读且没有想法时隐藏阅读笔记区，写想法入口移至文章操作栏。Agent 卡片移除归档出处行，底层会话来源信息保留。
- Agent 归档读取完整对话，围绕后续澄清中逐渐聚焦的问题提炼最终认识，省略被取代的观点和偏离主题的支线。默认一段、必要时两短段，不加标题或固定栏目，通常 100—250 字、最多 500 字符；保留决定性依据与不确定性，不改写历史归档。
- 正文（原文、译文、推文）及精读结论／要点共用高亮、引用提问和引用写想法菜单。高亮沿用原 SQLite 表和重新定位规则，支持刷新恢复、点击取消；渲染保留源文本偏移，处理 Markdown、重复文本与非 BMP 字符。原文新增 `original` 类型，旧类型、颜色与批注在迁移时保留。引用记录区分原文、译文、精读结论和要点。
- 来源和全部来源采用一致的行结构：新闻流显示未读数，稍后再看显示待阅读数，收藏显示收藏数；重要新闻和想法隐藏来源角标。收藏入口显示总数；状态变化后刷新，迟到响应不能覆盖新集合的计数。
- 展开和划词引用提问共用会话准备流程；没有会话时自动创建，已有空会话则同步当前保存的 runtime、模型及配置，首次发送前再次校准。会话开始对话后固定执行配置，重开保留历史；正文尚未就绪时等待抓取完成。会话准备期间禁用发送，切换文章不接收上一篇的迟到响应。
- 设置页选择框及展开菜单统一自绘，跟随主题，支持方向键、输入定位、Enter 确认、Esc 取消与点击外部关闭；长列表独立滚动，窄屏自动调整展开方向。
- Chat／新闻研究 Agent 与翻译模型采用相同的输入同步规则：目录模型清空自定义输入，自定义模型实时显示在选择框中，保存及重新进入设置后保持一致。翻译测试沿用 Agent 测试的标题、主按钮和结果终端。
- Codex 模型目录与推理档位保存在设置文件旁的 `.model-catalogs` 目录，按服务商、Profile 和 CLI 环境隔离；读取设置直接恢复缓存，手动刷新更新目录，刷新失败保留最后成功结果。目录获取不修改已选模型或其他设置草稿。
- Agent 顶部显示状态 Caption；新会话使用加号，发送与停止共用按钮，点击阅读栏外部区域收起。

Agent 的研究提示现在包含当前时间、优先使用现有检索工具、有限轮次查证和网络请求超时。OAR 会话在 90 秒或 6 次不同工具调用后请求汇总已有证据；这是软性收尾提示，不更改本机权限、不把部分回答伪报为成功。原有 300 秒硬超时和停止清理继续保留。`agent_jobs.progress` 以白名单阶段保存分析、检索、读取来源、服务重试和汇总状态，SSE 同步更新；不传递工具参数或凭据。

本轮真实隔离验证：完整英文快照问答约 16.5 秒成功；“最新进展如何？”完成外部检索与来源读取后约 30.4 秒成功。真实新闻、已读状态及历史对话未被测试修改。外部检索速度和服务可用性仍受上游影响。
