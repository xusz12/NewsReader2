# 阅读与研究指南

## 阅读与笔记

新闻流按日期分组，可按信源、分类和关键词筛选。「未读」和「稍后再看」的待阅读列表默认从旧到新。阅读途中有新闻入库时，点击「有 N 条新新闻」才会载入新一批，方便接着读完当前列表。

| 操作 | 结果 |
| --- | --- |
| 加入「稍后再看」 | 新闻设为已浏览，并排队抓取全文。正文准备好后，按钮显示「全文待看」。 |
| 在「稍后再看」主动打开「全文待看」的新闻 | 正文成功显示后记为已看完。也可点击卡片按钮标记完成，日后再次加入待阅读。 |
| 标记重要或收藏 | 新闻设为已浏览，全文阅读进度独立保存。 |
| 点击「全部已读」 | 先预览当前来源、搜索及分类范围的未读条数。确认后覆盖该范围内尚未加载的新闻，之后新入库的新闻仍为未浏览。 |

新闻浏览状态为「未浏览／已浏览」，全文阅读状态为「待阅读／已看完」。自动预取只准备正文缓存。[状态和界面名称对照](handoff/01-product.md#状态语义)

在阅读器中可切换「中英双语」，选中原文或译文添加四色高亮、写想法或引用给 Agent。点击已有高亮可换色，重复选择同色可取消。在「想法」打开新闻想法会回到对应报道，独立想法则用 Markdown 编辑，切换卡片会保留草稿与撤销记录。

顶栏可切换阅读字号，以及浅色、深色、跟随系统和墨水屏主题。手机从左上角导航进入研究功能。

### 快捷键

| 桌面操作 | 默认按键 |
| --- | --- |
| 上一条、下一条 | `w` 或 ↑、`s` 或 ↓ |
| 标记重要、稍后再看 | `a` 或 ←、`d` 或 → |
| 收藏、展开或收起 Agent | `f`、`q` |
| 搜索、设置、帮助 | `/`、`,`、`?` |

「设置 → 快捷键」可为每项操作录入最多两个按键或组合键，也可恢复默认设置。

## 新闻研究 Agent

1. 打开新闻，展开研究 Agent，直接提问或选中一段文字后引用提问。只有标题时也能开始对话，面板会提示全文尚未提供。
2. 在发送按钮旁选择当前会话的 Runtime、模型和推理强度。选择从下一轮起生效，全局默认值在「设置 → 模型与 Agent」中修改。新建会话可使用后来抓取的正文。
3. 回复完成后，点击「提炼结论追加到想法」。系统根据整场对话提炼仍有效的结论，最多 300 字符，作为一条新想法保存在该新闻下。[归档与会话规则](runtime-migration.md#归档与一次性会话)

桌面用 Enter 发送、Shift + Enter 换行。手机用 Enter 换行，点发送按钮或按 Ctrl / Cmd + Enter 发送。回复生成期间可编辑下一条草稿，也可停止当前任务。临时会话默认保留 72 小时，在设置中可改为 24 小时。

### Agent 回复通知

离开新闻或收起面板后，顶栏铃铛会保留待查看的回复。点通知可回到对应新闻、会话和那一轮回答。同一会话的多条回复合并显示。

窗口在前台且回复实际进入可见区域时，该条通知才清除。「全部标为已读」只处理点击时列出的通知。会话已过期或新闻无法打开时，可手动忽略通知。

## 主题追踪

1. 在「主题追踪」点加号，输入要跟踪的事件。Agent 联网拟定主题定义，可以继续对话或直接编辑名称、范围、收录规则和历史起点。
2. 点击「确认并整理历史」生成初始时间线。整理完成后，主题开始收录新入库的相关新闻。每篇新闻可归入多个主题。
3. 打开主题后，上方「重要进展」以一行节点展示事件脉络，下方「新闻时间线」先显示最近收录进主题的报道。点击新闻标题可阅读原文。点选进展节点可查看完整概述，带报道的节点还会筛选下方列表。

修改定义只影响之后入库的新闻。节点过多时，可用「精简进程」预览合并结果，再决定是否应用。归档主题会保留资料并停止收录，恢复后从新入库的报道继续。

创建主题和手动精简使用所选的研究 Agent。后续的主题归属和重要进展筛选由判断服务根据标题、摘要和收录规则完成。「主题追踪」入口的数量按有未查看更新的主题计算，打开相应主题详情后清除。

## 新闻分类与翻译

| 要配置的功能 | 设置入口 | 可选服务 |
| --- | --- | --- |
| 新闻分类、主题归属和重要进展筛选 | 新闻分类 | Jev 或 OpenAI Decisions，可启用另一家作为备用判断服务。 |
| 正文与采集字段翻译 | API 管理 → 正文翻译 | DeepSeek 或 OpenCode Go 订阅。可分别开关备用 API 和最后的 Pi 后备。 |
| 单篇对话、主题研究、积压总结和定期报告 | 模型与 Agent | 各功能分别选择 Pi 或 Codex，并可单独刷新模型目录、测试连接。 |

新闻流的「全部」也包含待分类和失败的新闻，「其他」只显示已判为其他的新闻。「设置 → 新闻分类」的环形图统计全库，下方队列则按已保存的「全部／仅未读」设置统计。分类并发默认 8，上限可设为 1–32。停用普通分类后，主题归属仍会继续。[分类规则](../classification/rules.json)

遇到限流时，服务会降低并发并等待重试。顶栏「任务进度」可查看阶段、数量和错误原因，失败项可在此重试。「清理异常」清除已查看的提示，任务继续按原排期执行。

密钥可存入系统钥匙串，环境变量优先。首次从旧项目迁入时，可在新项目重新保存密钥。Pi 和 Codex 使用各自的本机登录或配置。Codex 可手动刷新模型目录，Pi 在进入模型设置时重读可用凭据。[配置与环境变量](handoff/03-operations.md#配置清单) · [模型接入](handoff/03-operations.md#正文抓取和模型接入)

## 积压新闻总结

在「新闻总结」点击「总结并全部已读」，先看预览再确认。预览有效 15 分钟，会列出锁定的未读总数、实际用于写报告的材料数，以及归档后会一并标读的范围。

「设置 → 积压新闻总结范围」默认最多 20 个自然日、6,000 条新闻。这两个上限只决定写报告用多少材料。报告成功归档后，预览时锁定的全部未读都会设为已浏览。失败、取消和预览后新到的新闻保留原浏览状态。

历史报告支持搜索与 Markdown 导出。展开段落后附的报道来源可回到原文，返回时保留报告位置。早午晚报、周报和月报另按排期与新闻窗口生成。[定期报告说明](periodic-reports.md)
