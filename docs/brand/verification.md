# newsreader 方案 04 · 留白书签

更新日期：2026-10-16。

## 使用文件

- `mark.svg`：标准图形，建议 32px 及以上。
- `mark-small.svg`：16–24px 小尺寸版本，竖腔从 16 单位加宽为 24 单位。
- `mark-mono.svg` / `mark-reverse.svg`：单色与反白。
- `lockup.svg`：图形＋轮廓化衬线字标，透明背景、独立分组。
- `geometry.svg`：按实际坐标标注的几何骨架与负空间规范。
- `app-icon.svg` / `app-icon-192.png` / `app-icon-512.png` / `app-icon-1024.png`：通用应用图标。方形、不透明底板；由目标平台应用蒙版。此套资源不包含特定平台的完整安装图标包。
- `favicon.svg` / `favicon.ico` / `favicon-16.png` / `favicon-32.png` / `favicon-48.png`：浏览器图标。

## 几何约束

基准画布 128×128，u=4。标准主体宽 80、高 104，顶角 R8，切口深 20；r 的竖腔与右侧实体边壁宽度均为 16。四周安全留白至少 8 单位。

小尺寸版主体高 112，切口深 16，r 竖腔宽 24。不要直接给小图标加描边，或将负空间填实。组合标志的图形与字标间距不少于图形宽度的 1/4。

应用底板 1024×1024。主体宽 512，高 665.6；相对几何中心向上光学偏移 16。保持导出底板方形，避免同时使用文件圆角与平台蒙版。

## 已完成检验

实际 SVG 栅格化采用 resvg。检查 16、24、32、48、64、128px，分别以 1×、2× 输出，共 12 组。`proofs/size-raster-proof.png` 为尺寸总览，`proofs/favicon-pixel-detail.png` 为 16px 逐像素放大对比。

16px 小尺寸版在 y=floor(0.6×尺寸) 的竖腔采样线上，有 3 个连续像素的透明度 alpha≤32；2× 对应 6 个像素。这是限定截面的像素测量，不代表所有显示设备的主观识别保证。

应用 PNG 均解码检查为 192、512、1024px 方形，alpha 均为 255。ICO 检查为 3 个 32 位图层（16、32、48px），内嵌 PNG 签名、尺寸及数据范围有效。SVG XML 均可解析。

DOM 模拟环境检查：默认方案 04、切换早期方案 02、返回 04、浅深色主题传递到嵌入工作台、小尺寸标志槽位、下载文件存在，均通过。工作台脚本语法解析通过。这些检查不替代浏览器交互和布局实测。

图形对比度：陶土／暖纸 3.54:1；反白／陶土 3.70:1；反白／墨黑 17.50:1。图形均达到 3:1。陶土底的辅助文字使用墨黑（4.73:1），暖纸底的辅助文字使用深灰（5.98:1）。
