## 2026-10-27 分类数量与此次分类进度

- 二级分类复用主筛选的「名称 (数量)」写法，除「全部」始终不显示数量外，只在选中的按钮显示，包括0；计数未返回时显示省略号。数量复用当前范围的完整 `date_counts`，包含分页以外的新闻，随来源、关键词、阅读状态、标读／撤销和批量操作同步更新。只修改按钮文字与选中属性，保留按钮节点、焦点和横向滚动。
- 顶栏圆环与浮层读取分类接口的 `batch`，显示「此次已分类 X/Y 条」及本批待处理／处理中／失败数；历史已完成新闻不进入新批分子或分母。批次持久化，刷新／重启和失败重试沿用；处理中新增的新闻并入本批，本批结束后出现新任务再开始下一批。切换仅未读范围后按新范围建立批次，关闭／重新开启自动分类保留当前批次。
- 仅未读模式下，本批已完成新闻即使被标读也继续计数，在途任务完成后仍计入；尚未开始而被标读的新闻不再计入有效待处理数量。顶栏完成时隐藏，设置页全库覆盖率仍使用独立的 `coverage`，不混用两种统计。

## 2026-10-27 主题更新角标与中英双语

- 研究导航的 `#topicsNavBadge` 复用 `.nav-badge`，桌面侧栏和手机抽屉使用同一入口。`/api/nav-summary` 的 `topics_unseen` 表示有未查看更新的持续跟踪主题数：新收录新闻或重要进展更新均触发，同一主题只计一次；归档主题不计入。零值／首次加载隐藏，超过99显示99+，入口的可访问名称保留完整数量。沿用30秒导航统计刷新及窗口重新可见时刷新，失败保留原计数。
- 主题卡片沿用未读点；没有新新闻但有重要进展时显示「有新进展」。打开具体主题的完整详情才确认已查看，不因打开列表、手机停留列表、编辑定义、筛选报道、查看新闻正文或页面隐藏而清除。确认成功立即刷新列表及侧栏，只确认实际读取的快照截止时间，失败保留提示并在后续可见刷新中重试。新闻已读状态不受影响。
- 正文语言控件复用 `.digest-mode-tabs` / `.digest-mode-btn`，原「英文原文」改为「中英双语」，与「中文精读」切换；使用 `aria-pressed` 表达选择。只有正文翻译、没有精读摘要的文章也提供语言控件，想法区原有收起规则保持不变。
- 双语每组先原文后译文，`.bilingual-pair` 仅用共享 `--space-2` 设置组内间距，两种语言沿用 `.article-body` 的字体、颜色、1.7行高和全局阅读字号；组间沿用正文间距。标题、引用、列表和链接使用现有正文渲染，原文／译文分别保留完整原始偏移及各自的高亮与引用来源。
- 按空行分段并保持顺序；现有译文段数不匹配时完整分开显示两种正文，提示可重新翻译，不截断或强行交错。缺失一种正文时保留可用内容并说明。翻译与备用翻译提示统一要求保持段落数量、顺序和结构，不自动重新翻译已有文章。
- `tests/ui/bilingual-updates.spec.js` 覆盖角标确认、后台更新、刷新持久化、逐段顺序、双语高亮与引用、旧译文降级，以及手机／桌面、所有主题、断点和阅读字号。

回归对比：v0.0.15 与 v0.1.0 为固定 40px 单行 input、阅读器内底部绝对定位；v0.1.1 同时引入 textarea 自动测量、visualViewport 监听及阅读器内 fixed 定位。这使文本测量、键盘平移和带位移祖先的定位相互耦合。此次保留多行与快捷键，拆开测量和定位；新增回归覆盖聚焦后的测量写入、浏览器光标滚动、键盘视口和顶层面板的导航生命周期。桌面 WebKit 回归不等同于 iPhone 软键盘真机验证。
