## 依据优先级

统一入口为 [项目设计与协作规范](design-guidelines.md)：用户当前明确要求优先，其次为该文档的固定约定、本映射及对应 CHANGELOG，最后参考修订设计规范的基础规则。改变固定约定时同步更新相关文档；原型仅供历史对照。原型与修订规范并非处处同值：2026-10-23按用户指定采用原型手机顶栏50px与新闻卡片紧凑尺度，桌面顶栏52px、正文14px/1.7继续保留。不得用旧原型覆盖后来确认的产品交互。

## 2026-10-24 紧凑设置与快捷键

- 设置分类栏在921px及以上独立使用280px宽度，新闻列表仍为430px；手机保留整屏分类列表。中栏标题区最小52px、上下8px内边距，标题使用二级标题尺度并与右栏对齐。入口列表内边距8px 12px、行距4px；选中项使用浅强调底色、强调色文字和600字重，移除整圈强调色边框。
- 设置分类入口只保留图标、名称和箭头，移除「工作台偏好」、分类搜索、次级标签、入口说明、分类总数与保存提示；系统与版本位于首位并作为初始详情，切换后保留当前分类。入口参考左侧导航：桌面7px 10px内边距、最小36px高；手机8px 10px、最小40px高，18px图标、13px名称，不附加图标外框。
- 「快捷键」管理上一条、下一条、重要、稍后再看、收藏、已读、Agent、搜索、设置和速查。支持单键、Ctrl／Alt／Shift／Meta组合键，每个操作固定两个独立按键录入框，聚焦后直接按键录入，每框只记录一个单键或组合键，不接受分隔符文本。提供逐框清除与恢复默认，清空两个框后停用；录入时即时检查重复绑定，冲突或无效按键不覆盖原值。Esc 结束录入，Tab 移动焦点，Enter 保留用于确认；三者不可绑定。旧版超出两个的绑定保留前两个。
- 偏好保存在当前浏览器的 `newsreader_workbench_shortcuts`，仅修改这些偏好时不提交服务器模型／数据库设置。底部栏开关使用带滑块的 toggle，仅影响桌面快捷键栏，不影响手机主导航；栏最右侧关闭按钮立即保存隐藏状态，可在快捷键设置恢复。底栏内容横向溢出可滚动，右侧速查与关闭按钮保持可见。
- 保存／撤销按钮仅在配置与已保存值有差异时显示，手动改回原值、撤销或保存成功后隐藏。系统与版本初始不显示更新结果占位区域；发起检查或恢复实际更新状态后展示结果。
- 设置右栏标题区采用紧凑间距：桌面内边距8px 16px，手机8px 14px，最小高度52px、控件间距8px，标题无额外外边距。返回、标题、撤销与保存始终同排居中；窄栏按钮左右内边距8px、字号12px、按钮间距4px，保留完整按钮文字，过长标题单行省略并提供完整 title。
- 底栏、速查、正文按钮与搜索提示从同一绑定表更新。新闻、想法、总结和设置分类导航复用绑定；输入框、富文本、组合输入和弹窗保留自身操作。存储不可用时保持原生效绑定，并明确显示保存失败。

## 2026-10-24 新闻分类设置

- 新增「新闻分类」设置分类（`data-settings-tab="classification"`），位于 API 管理之后，复用既有设置工作台与窄屏返回交互。`#classificationSettings` 集中提供「启用自动分类」（默认开启）、「仅对未读新闻分类」（默认关闭）及「分类并发上限」（默认8，1–32整数）；「启用自动分类」使用滑块式 toggle，与底部快捷键栏开关共用样式，文字靠左、开关靠右；保留原生 checkbox 的 switch 语义、键盘操作、数值输入和全局保存／撤销流程。
- 总开关保存后生效：关闭后不再领取新分类任务，已发出的请求允许完成，队列和已有分类结果保留；重新开启后继续处理符合范围的任务。新闻分类筛选和已有标签仍可使用。关闭时隐藏顶栏分类进度、取消快速轮询；保存后立即刷新显示状态。
- 自动分类总开关取消勾选时，「仅对未读新闻分类」与「分类并发上限」立即置灰并通过原生 disabled fieldset 禁止操作、跳过键盘焦点；保留当前值，重新开启后恢复编辑。加载已关闭配置与撤销时同步禁用状态，API 管理入口仍可用于准备密钥与模型。
- API 管理只呈现各服务的密钥、模型、目录获取及连接测试，不再承载分类并发或未读范围。新闻分类中的「管理 Jev API」跳转到 API 管理并选中 Jev，保留两边草稿；进度卡片的「分类设置」入口跳转到新闻分类模块。
- 配置持久化到独立 `classification` 对象；已有 `api_models.jev.concurrency/unread_only` 自动迁移，保留模型和范围，默认延续自动分类开启状态。旧客户端保存 API 模型不会重置新分类配置。

## 2026-10-24 默认排序与抽屉阴影

- 新闻流「未读」及稍后再看「待阅读」默认按新闻日期、发布时间、ID 从旧到新；「全部」「已读」、重要新闻（含想法筛选）与收藏默认从新到旧，想法与总结继续按既有时间字段从新到旧。排序按钮图标和可访问名称、普通列表、搜索结果及游标分页采用相同方向；手动按钮反转当前方向。
- 切换集合或主筛选恢复该范围的默认排序；重复点击当前主筛选、切换二级分类／来源或展开／收起搜索保留手动排序。
- 1280px以下的 `.left-nav` 收起时使用 `box-shadow: none`，避免抽屉虽已移出屏幕、模糊阴影仍露在页面左边。仅 `.left-nav.drawer-open` 使用 `--shadow-float`，随浅色、深色、系统及墨水屏主题适配；保留原展开／收起位移、遮罩与焦点行为。

## 2026-10-24 面板外部点击

- `#agentDock` 展开且可见、`#upstreamErrorsPanel` 打开时，通过共享 `outside-dismiss.js` 在捕获阶段消费首次外部按下及随后释放／点击；范围覆盖阅读区、列表、导航与顶栏。首次点击只收起面板，不聚焦、不打开菜单、不触发外部按钮或链接；下一次独立点击正常操作。
- 面板内输入、按钮和报错日历正常使用；报错入口仍可再次点击关闭。报错面板关闭后焦点返回入口，Agent 沿用收起时的焦点处理并保留草稿。上层业务确认框、总结确认和快捷键帮助不受拦截；隐藏的 Agent 不阻挡页面操作。
- 鼠标和触屏共用同一规则；取消手势或改用键盘后不残留点击拦截。不改变面板的视觉样式、滚轮滚动及键盘导航规则。
- `#upstreamErrorsBackdrop` 与报错面板同步显示／隐藏，固定覆盖整个视口，位于面板和日历下方（z-index 249／250／260）。浅色、深色及跟随系统使用4px背景模糊与12%黑色遮罩，面板和日历保持清晰；墨水屏取消模糊和半透明遮罩。虚化层不捕获事件，外部点击继续由共享拦截器完整消费。

## 2026-10-24 移动端新闻搜索

- ≤920px时，`#feedSearchToggleBtn` 位于工具栏最右侧、`#markAllReadBtn` 右边，复用25×25px幽灵图标按钮；`aria-expanded` 表达激活态，展开时使用accent文字、accent-soft背景和淡accent边框。新闻流、稍后再看、收藏、重要新闻共用此入口；桌面保留常显搜索框。
- `#feedSearchRow` 默认收起且不占高度，在原来的搜索顶行展开；使用 `--motion-fast`（120ms）和 `--ease-standard` 过渡高度、透明度与4px位移。展开后立即聚焦原输入框，收起后输入区不可聚焦；输入搜索沿用250ms防抖。墨水屏与减少动态效果模式取消动画。
- 再次点击图标或在输入框按Esc收起，焦点返回图标，同时清空输入框和搜索关键词，取消待执行的搜索并中止旧请求，恢复当前集合、分类、来源、阅读状态和排序下的新闻列表；`/`快捷键展开并聚焦搜索框。920／921px断点切换仅同步可见性与焦点，桌面始终可搜索。想法、总结的独立搜索入口沿用原布局。

## 2026-10-24 新闻列表日期标题

- 新闻卡片列表按服务端 `date_key` 分组，顺序沿用当前排序；每组标题左侧显示 `YYYY-MM-DD`，右侧显示当前集合、二级分类、来源、关键词和阅读状态范围内当日的完整数量（包含未加载页），如「15 条」。未知日期显示「日期未知」。主筛选数量继续跨二级分类统计，二级分类按钮仅显示名称。
