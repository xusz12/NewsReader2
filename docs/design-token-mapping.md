## 依据优先级

## 2026-10-23 新闻分类（v0.2.1）

- `#newsCategoryFilters` 位于新闻流现有筛选行下方，顺序固定为全部、中国、AI、政治与国际、经济与金融、商业、科技与科学、其他；只在新闻流显示，进入其他集合不携带分类条件，返回新闻流保留选择。
- 复用 `.filter-chip`、`--surface`、`--fg`、`--muted`、`--border` 和间距 Token。单行横向滚动，`aria-pressed` 表达选中状态；Tab 可遍历，左右方向键与 Home／End 移动焦点，Enter／空格选择。计数刷新不重建按钮，保留焦点和滚动位置。
- 卡片页脚显示低强调的单一分类文字，不把失败或待处理渲染成「其他」。分类进度／缺少配置／失败提示仅在需要时出现；后台完成提示刷新，不主动跳动列表。
- API 管理的 Jev 面板增加「分类并发上限」数字输入（默认 8，1–32 整数），复用现有字段和保存流程；切换服务保留草稿。限流时复用分类提示显示实际／配置并发及剩余等待时间，不打断列表阅读。
- Jev 面板的「仅对未读新闻分类」默认关闭，沿用保存／撤销及服务切换草稿行为；使用原生 checkbox 的 `switch` 语义，支持空格键与整行标签点击。`.settings-toggle` 使用现有字号、间距与前景 Token，不增加外框；开启时进度明确显示「正在分类未读新闻」，已读队列不计入待处理进度。

## API 管理（v0.2.0）

- 原「DeepSeek 精读与翻译」扩展为「API 管理」，复用同页分类布局与 `SelectControls` 服务选择器，提供 DeepSeek、Jev 两项。内部 `deepseek` 分类标识继续兼容既有导航。
- 两项服务共用模型选择、自定义模型、密钥保存／更新／删除、获取模型及测试界面。模型草稿、密钥草稿、目录和测试结果按服务隔离；切换分类、关闭再打开设置均保留草稿，恢复已保存配置会丢弃旧探测结果。
- 密钥单独保存到钥匙串；环境变量优先并明确提示。测试使用已保存的密钥和当前模型草稿，修改模型后旧测试结果失效；请求失败保留有效目录，删除密钥保留模型选择。
- DeepSeek 继续控制单篇精读与翻译；Jev 管理 TypeSafe 原生判断模型，默认 `jev-latest`，本次提供配置与连接测试。两项服务按各自协议探测，不改变 Agent 的 Pi／Codex 配置。

## 2026-10-21 组件修复规则

- 主按钮与发布想法按钮保留原 `--accent` 底色，使用组件文字色 `--accent-button-fg`：浅色及墨水屏白字，显式深色及跟随系统深色使用该主题 `--bg` 深色字。普通文字的默认与悬停对比目标均不低于4.5:1；不改变链接和正文强调色。
- 模型及翻译连接测试终端在墨水屏使用 `--surface-subtle` 灰底、`--fg` 黑字和1px `--border`；浅色、深色保留终端现有样式。
- 独立想法正文仅在 `:focus-visible` 呈现2px accent外圈、2px偏移；失焦恢复无边框轻量编辑。设置详情h2明确600字重，字号与行高不变。
- 独立想法/总结的新增排版尺度及编辑器节点选择态尚需单独确认，不在本轮修复中改变。

## Agent 回复通知

顶栏右侧通知铃铛采用无边框图标按钮，默认透明边框、muted文字，悬停／键盘聚焦显示边界，待看状态使用accent和独立小圆点；墨水屏同时显示黑色边框，保留可访问名称和待看条数的屏幕阅读提示。下拉沿用surface、fg、muted、border-strong、radius-lg及shadow-float，手机固定在顶栏下并限制在屏宽内，移动底栏三项不变。通知按会话合并；点击跳转并定位具体回复，实际可见后才确认，打开列表本身不清除。

无全文的 Agent 会话在聊天区上方显示标题资料引用与“尚未提供全文”，沿用fg、muted、border及fs-meta；标题换行并限制为两行，完整标题保留在title说明中。标题提示与用户划线引用分别显示，不占用问题输入框。独立想法的语法速查仅随标题／正文／速查区焦点显示，移出后隐藏，保留折叠偏好与示例复制。

本次修复针对视觉规范。延续 v0.0.2／v0.0.3 已确定的功能范围：阅读导航保留新闻流、稍后再看、重要新闻、收藏、想法；不重新引入日报、提醒、复盘、跟踪和板块。阅读器保留现有离散操作，标读快捷键与卡片稍后看流程保持原有语义；空笔记入口和 Agent 归档出处行的既有精简保持不变。设置继续按分类切换右栏配置，而非一次展示全部表单。

## v0.1.1 界面修订

更新结果使用surface-subtle、border-strong和fg，主要结论为fs-body／600，说明与时间为muted／fs-meta，状态同时通过文本表达。刷新索引与铃铛共用topbar-ghost-btn，只影响这两个按钮。上游报错采用通知同类surface、border-strong、radius-lg、shadow-float非模态面板，视口两侧至少12px，内部记录滚动；与通知互斥。Agent textarea桌面默认两行、手机默认一行，桌面约八行／手机约五行和可见视口三分之一双重上限，手机16px，发送按钮固定可操作，软键盘视口变化重新布局。

### 手机 Agent 面板（2026-10-22）

- 展开高度约为当前窗口的 70%，限制在 `visualViewport` 可见区域内，避开顶栏和可见底栏。手机展开时将面板挂载到 `body`，脱离阅读器的 `transform` 和 `overflow` 祖先；收起、退出阅读器、进入设置或切回桌面时归还原位置。键盘事件只更新顶层面板的可视边界，不移动 DOM、不切换展开状态。
- 展开时不自动聚焦手机输入框；点击后输入，空内容默认一行，多行输入仍自适应增长，清空后恢复一行。桌面默认两行和发送快捷键不变。
- 手机不显示顶部把手及扩大／还原窗口按钮，不提供把手拖动；桌面保留扩大／还原窗口按钮。沿用标题栏与收起按钮，保留草稿。手机面板不对键盘引起的位置和高度变化做过渡动画。
- 自适应输入框使用不可聚焦、辅助阅读隐藏的副本测量；不在每次 focus／视口滚动时把真实 textarea 高度设为 `auto` 再读 `scrollHeight`。仅尺寸确实变化时写入真实输入框，避免干扰 iOS 的光标可见性滚动。

回归对比：v0.0.15 与 v0.1.0 为固定 40px 单行 input、阅读器内底部绝对定位；v0.1.1 同时引入 textarea 自动测量、visualViewport 监听及阅读器内 fixed 定位。这使文本测量、键盘平移和带位移祖先的定位相互耦合。此次保留多行与快捷键，拆开测量和定位；新增回归覆盖聚焦后的测量写入、浏览器光标滚动、键盘视口和顶层面板的导航生命周期。桌面 WebKit 回归不等同于 iPhone 软键盘真机验证。

共享应用确认框复用catchup-dialog的surface-raised、border-strong、radius-lg和shadow-float；动作文本采用纯文本，默认取消，关闭均取消，焦点留在框内并返回可用触发按钮。报错日历沿用surface／fg／muted、七列日期和焦点环，当前日用边框/下划线、选中日用fg/surface反色区分；日期文本输入校验错误就地显示，月份浏览不触发查询。

## 2026-10-22 移动端角标与阅读字号

- `#mobUnreadBadge`、`#mobReadLaterBadge` 分别使用 `/api/nav-summary` 的 `feed_unread`、`read_later_unread`，与现有导航统计和标读更新共用渲染入口。零条及首次等待统计时隐藏；超过 99 显示 `99+`，按钮可访问名称保留完整数量。稍后再看统计沿用全文待阅读口径。角标使用 accent／accent-button-fg 配色，兼容四种主题。
- `#fontSizeSelect` 复用 `SelectControls`，提供小、标准、大、特大四档（90%、100%、115%、130%），标准保持原有字号。桌面显示 `Aa` 和当前选项，手机为 36px 的 `Aa` 入口，菜单保留完整选项和当前值描述。偏好保存在本浏览器的 `newsreader_workbench_font_size`，首屏读取，非法值或存储不可用时采用标准。
- 应用补充变量 `--reading-scale` 仅用于阅读内容的字号计算，覆盖新闻列表、正文、精读、已存想法、独立想法、总结及 Agent 消息。导航、按钮、表单与 Agent 输入框不缩放；基础 CSS／JSON Token 保持不变。顶栏在中等宽度按可用空间截断同步状态文本，保持所有操作入口可用。
- `tests/ui/reading-preferences.spec.js` 覆盖角标零值／更新／大数、字号持久化与存储异常、内容缩放和控件尺度，以及主题和响应式边界。
