# 产品范围与交互约定

News Reader Workbench 将每日新闻文件索引为可搜索的新闻流，保存阅读状态、全文、中文精读、划线和个人想法，并通过本机 Pi 或 Codex 执行单篇研究和积压新闻总结。当前版本为 v0.0.15。

## 功能范围

| 功能 | 当前行为 | 依赖及验收重点 |
| --- | --- | --- |
| 新闻流 | 增量索引、信源筛选、搜索、排序、分页和批量标读 | 需要 DailyNews 输入；默认未读、旧到新 |
| 稍后再看 | 加入后将新闻浏览状态设为已浏览并排队抓取全文；全文阅读状态独立记录 | opencli；区分排队、抓取、失败、全文待看和已看完 |
| 重要与收藏 | 单篇切换，独立集合；开启时自动设为已浏览，取消不回退；全文阅读状态独立；收藏支持全部取消 | SQLite 状态持久化；全部取消覆盖筛选之外的收藏 |
| 中文精读 | 保存中文正文、要点及核心结论，列表展示已抓取文章的核心结论 | 翻译配置和模型凭据；无结论时不伪造预览 |
| 划线与新闻想法 | 原文、译文、要点、结论高亮；引用写想法；多条个人及 Agent 评论 | 刷新后恢复；引用与作者元数据保持完整 |
| 独立想法 | 可选标题，Markdown 即时编辑、草稿、撤销和显式保存 | ProseMirror；正文以 Markdown 存储 |
| 单篇研究 Agent | 会话、流式回答、停止、重试、新会话、归档到新闻想法 | Pi/OAR 或 Codex；上下文依赖可用正文 |
| 主题追踪 | 联网明确事件定义，可多轮对话协商，明确点击确认后整理历史，再追踪新入库新闻；横向节点＋纵向报道，支持归档／恢复和列表筛选 | Jev多主题归属与横向筛选，Pi/Codex定义对话与初始化研究；创建后可修订规则，新主题仅重要进展，不定期联网 |
| 新闻总结 | 预览范围、确认执行、历史搜索、来源追溯、Markdown 导出 | 使用 Agent 配置；保存报告与整批标读在同一事务中完成 |
| 设置 | 系统与版本、模型与 Agent、API 管理、新闻分类、信源、数据、总结范围、快捷键 | 分类模块管理自动分类开关、未读范围与并发；API 管理仅管理密钥与模型；快捷键与底栏显隐保存在当前浏览器。草稿与保存值分开 |
| 同步及报错 | 自动刷新索引、当日来源可用率、入库条数及上游报错浏览 | 来源是输入日报的采集记录；不是服务器异常监控平台 |
| 主题与适配 | 浅色、深色、跟随系统、墨水屏；桌面及移动端布局 | 360–1920 像素已有浏览器测试覆盖 |
| 兼容功能 | 日报、提醒、复盘、跟踪、板块等后端接口和历史表仍保留 | 当前主要界面无对应完整入口；不能据此删除旧数据 |

## 状态语义

2026-11-02 核对当前实现，统一以下官方术语。后续需求、文档、开发说明与验收使用这些名称；引用现有界面或旧接口时注明所属状态，不再把两套状态都简称为“已读／未读”。新闻浏览状态成功保存后不可逆；接口字段与既有筛选文案保持兼容，移除标为已读／未读快捷键。

新闻列表的一条记录由 `items.id` 标识。同一日期和 URL 对应稳定 ID；新闻浏览状态、全文阅读状态、重要、收藏等记录存在 `item_state`。全文、中文精读、新闻想法和划线主要按 URL 关联，因此同一 URL 的跨日期记录可以共享正文与想法，但拥有各自的新闻浏览状态与全文阅读状态。

| 官方名称 | 官方状态值 | 含义与数据依据 |
| --- | --- | --- |
| **新闻浏览状态** | **未浏览／已浏览** | 是否已在新闻流中浏览或处理这条新闻；`read_at` 为空／有值。新闻流红点与主题时间线 `new` 共用，不表示读完全文 |
| **全文阅读状态** | **待阅读／已看完** | 稍后再看中的阅读完成情况，与 `read_at` 独立；由 `read_later_at`、`read_later_done_at` 及正文是否已缓存共同确定 |

全文阅读状态的范围与判定：

- **待阅读**：已加入稍后再看（`read_later_at` 有值），或已有缓存正文且尚无完成记录（`read_later_done_at` 为空）。包含尚在排队、抓取中或抓取失败的条目，不只包含全文已就绪的新闻。
- **已看完**：`read_later_done_at` 有值且 `read_later_at` 为空。在稍后再看主动打开且正文已显示，或显式完成阅读时记录；再次加入稍后再看可恢复待阅读。
- 未加入稍后再看、无缓存正文且无完成记录的新闻不属于该集合，不应仅因完成时间为空就称为“待阅读”。

**排队中、抓取中、抓取失败、全文待看**描述全文准备阶段。其中“全文待看”表示正文已就绪、全文阅读状态仍为待阅读。默认选中卡片、后台刷新、全文刚抓取完成均不能自动判定“已看完”。运行中的抓取不能因取消排队而被误报为已终止；重试或重新加入不能重置仍在运行或等待重试的任务。

### 当前操作对两套状态的影响

| 操作 | 新闻浏览状态 | 全文阅读状态 |
| --- | --- | --- |
| 加入稍后再看 | 未浏览 → 已浏览；已浏览保持原状态与浏览时间 | 进入待阅读，不记为已看完 |
| 标记重要／收藏 | 未浏览 → 已浏览；已浏览保持原状态与浏览时间 | 保持原状态 |
| 取消重要／收藏（含全部取消收藏） | 不恢复未浏览 | 保持原状态 |
| 取消稍后再看的排队 | 不恢复未浏览 | 不视为看完；有缓存正文时仍属待阅读，无正文且无完成记录时退出该集合 |

新闻浏览状态一旦成功保存为已浏览，就不能再改回未浏览。加入稍后再看、标记重要或收藏均会联动已浏览；取消任一标记不回退。状态接口拒绝所有 `read: false` 请求，含其他标记的混合请求也整次拒绝，不作部分写入。重复标记保留首次浏览时间。前端保存失败时恢复尚未成功提交的真实状态，过期响应不能覆盖已保存状态。以现有数据为起点，不追溯标记历史重要／收藏新闻；历史缓存正文自动进入待阅读时，也不追溯修改新闻浏览状态。

新闻浏览状态可由新闻流滚动／批量操作、主题详情连续可见6秒、加入稍后再看、标记重要／收藏或成功的新闻总结设为已浏览。主题计时处理当前快照内全部未浏览新闻，包括未加载分页；不增加逐条打开或滚动标记。任一处设为已浏览后，其他主题的 `new` 和新闻流未浏览标记同步清除，已浏览新闻不会因取消标记重新显示这些提示。重要进展的查看状态仍按主题独立保存。

### 现有界面与接口的名称映射

| 现有名称或字段 | 官方含义 |
| --- | --- |
| 新闻流“未读／已读”、旧文档“新闻全局已读” | 新闻浏览状态：未浏览／已浏览 |
| 新闻流“全部已读”、旧文档“标读” | 将范围内的新闻设为已浏览 |
| 稍后再看“待阅读／已读”筛选 | 全文阅读状态：待阅读／已看完 |
| 稍后再看“全文待看”按钮 | 全文已就绪且仍待阅读 |
| 稍后再看“已看完／全部看完” | 全文阅读状态为已看完／将范围内条目设为已看完 |
| `feed_unread` | 未浏览新闻数 |
| `read_later_unread` | 待阅读新闻数 |

`read_filter=unread/read` 是兼容接口值：在新闻流表示未浏览／已浏览，在稍后再看表示待阅读／已看完。两者必须结合 `collection` 解读，不能混用计数或相互覆盖。下文及历史文档中的原界面名称按此表理解；后续新增说明使用官方术语。

## 必须保留的体验规则

- 移动端底栏固定为“新闻流、稍后再看、收藏”，顺序不变。新增功能入口放入导航抽屉；只有明确的产品决策才能改变这一约定。
- 移动端主题切换使用图标，保留可访问名称、当前主题说明及菜单中的完整主题名称。
- 1280px 起为导航、列表、正文三栏；921–1279px 收起导航；920px 及以下为单栏切换。顶栏 52px、导航 248px、新闻列表 430px、正文最大 760px；设置分类栏在921px及以上为280px，手机仍为整屏列表。
- 新闻流「未读」与稍后再看「待阅读」默认旧到新，其余筛选、重要和收藏默认新到旧；想法按更新时间新到旧。切换集合或主筛选恢复默认排序，分类、来源与搜索保留当前手动排序。列表按日期分组并显示当日完整数量，卡片仅展示时间（2026-10-24更新）。
- 新闻流卡片滑出列表顶部才自动标读；列表末尾停留 5 秒只标读当前加载范围。计数立即更新，后台失败要恢复，过期响应不得覆盖新状态。
- “全部已读”先展示来源、搜索条件和最新匹配数量；确认后覆盖未加载的匹配新闻。它与新闻总结的整批锁定规则是两个不同流程。
- 新闻想法复用新闻阅读器；独立想法直接编辑。条目切换保留本次页面会话内的草稿和撤销历史，迟到保存响应不能覆盖后续输入。草稿不保证在刷新或关闭页面后恢复。
- 移动端从左边缘 40px 内向右滑动超过 72px 可返回列表；正文纵向滚动、选中文字、输入控件和 Agent 对话不得误触返回。
- 快捷键包括 `w/s` 或上下方向键浏览，`a/←` 重要，`d/→` 稍后，`f` 收藏，`q` Agent，`/` 搜索，`,` 设置，`?` 帮助。标为已读／未读快捷键及其设置、提示、旧自定义绑定均已移除；`m` 也不再用于全文完成。输入控件内不得误触全局操作。2026-10-24新增「快捷键」设置：每项固定两个按键录入框，直接按键设置并即时检查冲突，支持逐框清除／恢复默认；快捷键栏 toggle 显隐与绑定保存在当前浏览器，保存后同步提示与速查；Esc、Tab、Enter为保留操作。

## 新闻总结的特殊约定

预览锁定当时的全部未读，包含已关闭信源，排除 Bloomberg 视频。默认最多 20 个自然日、6000 条，再受完整请求 2 MiB 限制。日期、条数和大小限制决定进入模型的材料；**成功归档后会标读全部锁定未读，包括明确告知用户但未进入模型的部分**。

预览有效期为 15 分钟；配置或数据库发生变化需要重新预览。失败、取消、结果校验失败不标读；新到新闻不进入旧批次。历史报告及来源引用保存到新闻主库。单篇研究可以检索外部资料，积压总结按锁定材料执行，并限制额外工具操作。

## 当前不提供的产品能力

应用没有多用户账户、团队权限、云同步后台、独立采集调度器或通知服务。Web manifest 和主屏幕图标不代表已提供离线 PWA。独立想法标题最多 200 字符、正文最多 5000 字符，使用 CommonMark 模型，GFM 表格和任务列表未作为专用块支持。后续若扩展这些能力，应独立立项并补充验收标准。
