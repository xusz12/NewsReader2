# 产品范围与交互约定

News Reader Workbench 将每日新闻文件索引为可搜索的新闻流，保存阅读状态、全文、中文精读、划线和个人想法，并通过本机 Pi 或 Codex 执行单篇研究和积压新闻总结。当前版本为 v0.0.15。

## 功能范围

| 功能 | 当前行为 | 依赖及验收重点 |
| --- | --- | --- |
| 新闻流 | 增量索引、信源筛选、搜索、排序、分页和批量标读 | 需要 DailyNews 输入；默认未读、旧到新 |
| 稍后再看 | 加入后排队抓取全文；区分排队、抓取、失败、全文待看和已看完 | opencli；与新闻流已读状态独立 |
| 重要与收藏 | 单篇切换，独立集合；收藏支持全部取消 | SQLite 状态持久化；全部取消覆盖筛选之外的收藏 |
| 中文精读 | 保存中文正文、要点及核心结论，列表展示已抓取文章的核心结论 | 翻译配置和模型凭据；无结论时不伪造预览 |
| 划线与新闻想法 | 原文、译文、要点、结论高亮；引用写想法；多条个人及 Agent 评论 | 刷新后恢复；引用与作者元数据保持完整 |
| 独立想法 | 可选标题，Markdown 即时编辑、草稿、撤销和显式保存 | ProseMirror；正文以 Markdown 存储 |
| 单篇研究 Agent | 会话、流式回答、停止、重试、新会话、归档到新闻想法 | Pi/OAR 或 Codex；上下文依赖可用正文 |
| 新闻总结 | 预览范围、确认执行、历史搜索、来源追溯、Markdown 导出 | 使用 Agent 配置；保存报告与整批标读在同一事务中完成 |
| 设置 | 模型、信源、数据、总结范围、系统和更新等分类表单 | 草稿与保存值分开；环境变量可优先于表单 |
| 同步及报错 | 自动刷新索引、当日来源可用率、入库条数及上游报错浏览 | 来源是输入日报的采集记录；不是服务器异常监控平台 |
| 主题与适配 | 浅色、深色、跟随系统、墨水屏；桌面及移动端布局 | 360–1920 像素已有浏览器测试覆盖 |
| 兼容功能 | 日报、提醒、复盘、跟踪、板块等后端接口和历史表仍保留 | 当前主要界面无对应完整入口；不能据此删除旧数据 |

## 状态语义

新闻列表的一条记录由 `items.id` 标识。同一日期和 URL 对应稳定 ID；阅读、重要、收藏等状态存在 `item_state`。全文、中文精读、新闻想法和划线主要按 URL 关联，因此同一 URL 的跨日期记录可以共享正文与想法，但拥有各自的新闻流阅读状态。

| 状态 | 含义 | 触发规则 |
| --- | --- | --- |
| 新闻流已读 | `read_at` 有值 | 手动、批量、滚动或成功的新闻总结 |
| 待抓取 | 加入稍后再看但尚无全文 | 创建正文抓取任务；未开始任务可以取消 |
| 全文待看 | 已有正文且未记录看完 | 不要求 `read_later_at` 仍有值，历史全文也能进入待阅读 |
| 已看完 | `read_later_done_at` 有值 | 在稍后再看主动打开且正文已显示，或显式完成阅读 |
| 抓取失败 | 正文任务失败 | 显示实际错误，用户可重试 |

默认选中卡片、后台刷新、全文刚抓取完成均不能自动判定“已看完”。运行中的抓取不能因取消排队而被误报为已终止。重试或重新加入不能重置仍在运行或等待重试的任务。

## 必须保留的体验规则

- 移动端底栏固定为“新闻流、稍后再看、收藏”，顺序不变。新增功能入口放入导航抽屉；只有明确的产品决策才能改变这一约定。
- 移动端主题切换使用图标，保留可访问名称、当前主题说明及菜单中的完整主题名称。
- 1280px 起为导航、列表、正文三栏；921–1279px 收起导航；920px 及以下为单栏切换。顶栏 52px、导航 248px、列表 430px、正文最大 760px。
- 新闻流默认未读、旧到新；稍后再看旧到新；重要和收藏新到旧；想法按更新时间新到旧。列表不展示日期分组标题，卡片展示完整日期时间。
- 新闻流卡片滑出列表顶部才自动标读；列表末尾停留 5 秒只标读当前加载范围。计数立即更新，后台失败要恢复，过期响应不得覆盖新状态。
- “全部已读”先展示来源、搜索条件和最新匹配数量；确认后覆盖未加载的匹配新闻。它与新闻总结的整批锁定规则是两个不同流程。
- 新闻想法复用新闻阅读器；独立想法直接编辑。条目切换保留本次页面会话内的草稿和撤销历史，迟到保存响应不能覆盖后续输入。草稿不保证在刷新或关闭页面后恢复。
- 移动端从左边缘 40px 内向右滑动超过 72px 可返回列表；正文纵向滚动、选中文字、输入控件和 Agent 对话不得误触返回。
- 快捷键包括 `w/s`、方向键或 `k/j` 浏览，`m` 标读，`a/←` 重要，`d/→` 稍后，`f` 收藏，`q` Agent，`/` 搜索，`,` 设置，`?` 帮助。输入控件内不得误触全局操作。

## 新闻总结的特殊约定

预览锁定当时的全部未读，包含已关闭信源，排除 Bloomberg 视频。默认最多 20 个自然日、6000 条，再受完整请求 2 MiB 限制。日期、条数和大小限制决定进入模型的材料；**成功归档后会标读全部锁定未读，包括明确告知用户但未进入模型的部分**。

预览有效期为 15 分钟；配置或数据库发生变化需要重新预览。失败、取消、结果校验失败不标读；新到新闻不进入旧批次。历史报告及来源引用保存到新闻主库。单篇研究可以检索外部资料，积压总结按锁定材料执行，并限制额外工具操作。

## 当前不提供的产品能力

应用没有多用户账户、团队权限、云同步后台、独立采集调度器或通知服务。Web manifest 和主屏幕图标不代表已提供离线 PWA。独立想法标题最多 200 字符、正文最多 5000 字符，使用 CommonMark 模型，GFM 表格和任务列表未作为专用块支持。后续若扩展这些能力，应独立立项并补充验收标准。
